## 1. 产品概述

### 1.1 产品定位

帧集 FrameLab 是面向全国高校视觉传达设计、数字媒体艺术、广告设计、新媒体艺术设计专业在校学生的**全链路设计师成长平台**，以「审美积累 — 创意分析赋能 — AI 辅助创作 — 阶梯技能训练 — 商业接单实战 — 实习就业落地」为完整生命周期闭环。

- **一句话定位**：设计学生从零基础到商业就业的一站式成长操作系统
- **Slogan**：每一帧成长，都算数
- **产品形态**：Web 端平台（PC 主站 + 移动端适配），账号体系打通全部模块

### 1.2 解决的核心问题

| 痛点 | 现状 | FrameLab 解法 |
|---|---|---|
| 审美积累薄弱、看图盲目 | 教程平台只给资源，无标准 | 美学赏析素材库 + 量化美学评分 |
| 创意枯竭、作品同质化 | 通用 AI 工具不懂学生痛点 | 创作焦虑大数据 + 专属灵感 AI 接口 |
| 创意无法落地、渲染差 | 多平台切换、出图不稳 | 双模型 AI 绘画引擎（平面 + 三维写实） |
| 实训松散、无验收标准 | 碎片化学习、无梯度 | 四级阶梯闯关实训体系 |
| 接单内卷、实习无通道 | 接单平台低价内卷、求职无法验证能力 | 派单大厅 + 智能匹配 + 创作者主页背书 |

### 1.3 差异化壁垒

1. **美学标准化**：全平台唯一的统一美学评分基准（六大维度量化打分）
2. **学生专属灵感 AI**：基于数万条真实创作焦虑舆情数据训练的垂直提示词库，非通用 AI 成品接口
3. **双模型引擎**：NanoBanana（平面/国风/新媒体）+ Lib AI（三维/写实/渲染）双模型互补
4. **能力可验证**：闯关数据 + 美学评分 + 接单信用构成可信能力档案，解决"求职无法验证真实能力"

## 2. 目标用户与画像

| 画像 | 阶段 | 核心诉求 | 主用模块 |
|---|---|---|---|
| 小林（大一新生） | 零基础 | 软件不会用、不知道什么是好设计 | 闯关 L1 + 美学赏析每日推送 |
| 阿哲（大二） | 有基础、无风格 | 作品同质化、配色构图固化 | 灵感 AI + 美学赏析风格库 |
| 悦悦（大三） | 备赛备作品集 | 比赛作品缺亮点、渲染质感差 | AI 创作中心 + 闯关 L3/L4 |
| 学长（大四） | 求职变现 | 接单无渠道、实习无背书 | 派单大厅 + 创作者主页 |

**核心用户旅程**：注册 → 测评定级 → 每日美学积累 → 闯关训练 → 灵感 AI 破局 → AI 出图落地 → 作品沉淀 → 通关解锁派单 → 接单/实习 → 能力档案背书就业。

## 4. 核心功能详述

### 4.1 模块一：美学赏析素材库

**功能清单**

| 功能 | 说明 | 优先级 |
|---|---|---|
| 风格/流派/关键词三维检索 | 一级四大板块 + 二级流派、风格、适用场景细分 | P0 |
| 每日美学推送 | 每日 3 张精选素材 + 五维美学解析文案 | P0 |
| 收藏对标库 | 跨模块调取（闯关/AI 创作/接单时一键参考） | P0 |
| 双案例同屏对比 | 色彩、构图、视觉气质差异直观对比 | P1 |
| 素材详情页 | 构图亮点/色彩逻辑/视觉层级/美学韵律/可借鉴点五维解析 | P0 |
| 美学评分模型 | 构图完整性、色彩适配度、视觉层级、留白合理性、风格统一性、创意美感六维打分 | P1 |

**素材入库标准**：官方授权渠道（WikiArt、大都会、卢浮宫、Behance、Dribbble、站酷等）；1080P+ 高清、无水印、无侵权；统一命名「风格 - 作品名称 - 作者 - 年份 - 适用场景」；每张素材人工撰写五维解析。

**关键流程**：学生筛选风格 → 浏览素材 → 查看五维解析 → 收藏对标 → 在创作/作业/接单中调取参考。

### 4.2 模块二：灵感 AI 工坊

**功能清单**

| 功能 | 说明 | 优先级 |
|---|---|---|
| 痛点输入面板 | 创作主题 + 当前风格 + 自身痛点 三项结构化输入 | P0 |
| 六维创意输出 | 差异化创意方案、小众风格推荐、创新构图思路、高级配色体系、画面亮点设计、避坑指南 | P0 |
| 五大专项提示词库 | 反同质化风格 / 小众构图 / 高级配色 / 主题落地 / 商业差异化 | P0（后台） |
| 痛点分析报告 | 四大高频痛点可视化（风格同质化 / 创意匮乏 / 构图配色固化 / 主题难落地） | P1 |
| 调用记录留存 | 每次灵感调用云端记录，用于行为分析与迭代 | P1 |
| 一键流转 AI 创作 | 创意方案直接复制输入 AI 创作中心生成草图 | P0 |

**接口逻辑**：不做通用 AI 套壳，基于通用大模型二次定制；内置敏感词过滤、侵权规避、原创引导；针对海报/文创/IP/产品渲染/新媒体视觉五类高频场景调优。

### 4.3 模块三：AI 创作中心

**功能清单**

| 功能 | 说明 | 优先级 |
|---|---|---|
| 双模型一键切换 | NanoBanana（平面/国风/新媒体）⇄ Lib AI（三维/写实/渲染），平台内无缝切换 | P0 |
| 八大创作功能 | 文生图、图生图、线稿上色、风格迁移、高清重绘、细节优化、灵感一键出图、作品存档 | P0 |
| 参数预设 | 海报 16:9、文创方版、产品竖版、封面全屏；风格阈值、渲染强度标准化 | P0 |
| 风格库联动 | 一键套用美学赏析库内置高级风格 | P0 |
| 云端作品库 | 自动归类风格标签，直接用于闯关作业/比赛投稿/商业接单/作品集 | P0 |
| 版权风控 | 创作记录、参数、灵感来源云端永久留存作为原创依据；内容审核过滤违规画面 | P1 |

### 4.4 模块四：闯关实训

**四级阶梯体系**

| 阶段 | 主题 | 实训命题 | 适配人群 |
|---|---|---|---|
| L1 软件基础 | PS 工具、选区、图层、蒙版、文字、修图、合成 | 基础合成小练 | 零基础新生 |
| L2 平面进阶 | 版式网格、视觉层级、字重色彩、海报构图 | 校园海报、文创平面、新媒体封面 | 有基础学生 |
| L3 三维建模 | 三维造型、立体构图、光影材质、渲染 | 产品建模、立体视觉 | 进阶学生 |
| L4 商业高阶 | 整合审美/软件/平面/三维 | 商业文创 IP、产品外观、品牌视觉、完整物料 | 高阶学生 |

**关卡机制**：每关「知识点学习 → 随堂小练 → 完整命题作业 → 美学评分 → 综合通关判定」；通关分 = 规范正确率 × 权重 + 美学得分 × 权重 + 创意得分 × 权重 + 完整度 × 权重；达标自动解锁下一阶段，未达标自动推送薄弱知识点与补学内容。

**数据沉淀**：学习成长图谱（每关得分、薄弱模块、进步轨迹）+ 作品自动打风格/技能/难度标签，纳入作品集生成体系。

### 4.5 模块五：派单大厅 + 实习对接

**功能清单**

| 功能 | 说明 | 优先级 |
|---|---|---|
| 甲方入驻发布端 | 实名认证、发布需求（预算/周期/交付标准）、平台冻结保证金防白嫖 | P0 |
| 派单大厅 | 学生浏览、筛选、抢单；按闯关等级/作品风格/能力标签智能匹配推送 | P0 |
| 创作者主页 | 聚合实训作品、AI 作品、美学评分、技能标签、成长数据；甲方一键邀约 | P0 |
| 履约体系 | 接单→交付→初审→验收→评价→结算 全流程 + 信用分机制 | P0 |
| 实习对接 | 企业按风格/能力等级筛选储备人才，发布岗位、定向邀约面试 | P1 |
| 风控仲裁 | 交易风控、原创审核、版权保护、纠纷仲裁 | P1 |

**智能匹配算法**：五维加权 —— 闯关通关率、作品美学评分、擅长风格、接单评价、学习稳定性 → 订单/实习机会优先级。

## 5. 跨模块联动（产品核心闭环）

```
美学赏析（标准） ──风格/评分基准──→ 闯关实训考核、AI 生图风格、派单审美评价
灵感 AI（创意） ──创意方案──→ AI 创作中心出图；反向扩充美学库与提示词库
AI 创作中心（落地）──成品──→ 闯关作业提交、作品集、派单交付
闯关实训（能力）──等级/标签──→ 派单匹配权重、创作者主页档案
派单大厅（出口）──实战履历/收益──→ 反哺学习动力，构成「学练创赛商职」六位一体
```

## 6. 页面与原型说明

原型共 7 个页面，导航结构、页面布局、核心交互如下：

| 页面 | 布局 | 核心交互演示 |
|---|---|---|
| 首页·工作台 | 学习进度环 + 今日美学推送 + 快捷入口 + 成长概览 | 呈现全链路总览与每日任务 |
| 美学赏析 | 筛选器 + 素材瀑布流 + 详情弹层 | 风格筛选、五维解析查看、双案例对比模式 |
| 灵感 AI 工坊 | 三项输入面板 + 六维结果输出 | 表单输入 → 模拟 AI 生成 → 一键发送 AI 创作 |
| AI 创作中心 | 双模型切换 + 参数面板 + 出图画廊 | 模型切换、比例预设、模拟生成 loading、作品存档 |
| 闯关实训 | 四级闯关地图 + 关卡列表 | 阶段解锁状态、关卡详情、通关评分展示 |
| 派单大厅 | 订单卡片流 + 匹配度标签 + 实习岗位侧栏 | 匹配度展示、抢单反馈 |
| 创作者主页 | 能力档案头 + 作品网格 + 成长数据条 | 六维美学雷达展示、信用分、技能标签 |

原型使用纯前端模拟数据，不含真实后端调用；AI 生成、评分等均为演示态模拟。

## 7. MVP 版本规划

| 版本 | 范围 | 验证目标 |
|---|---|---|
| V1.0 MVP | 美学赏析库（含每日推送）+ 闯关 L1/L2 + 账号体系 | 验证「标准化审美 + 闯关」学习留存 |
| V1.5 | 灵感 AI 接口 + AI 创作中心（先接单模型） | 验证 AI 赋能对创作频次/质量的提升 |
| V2.0 | 闯关 L3/L4 + 派单大厅（保证金/履约/信用分） | 验证商业闭环与接单 GMV |
| V2.5 | 实习对接 + 创作者主页对外分享 | 验证就业转化 |

**关键北极星指标**：学生月均创作作品数；辅助指标：闯关通关率、美学评分提升幅度、派单履约完成率、实习转化率。

## 8. 风险与边界

- **版权合规**：素材仅取官方公开授权渠道；AI 生成内容留存全链路记录作为原创依据；禁止模板搬运与抄袭生成。
- **内容风控**：灵感接口内置敏感词过滤与侵权规避；AI 出图内置内容审核。
- **交易风控**：甲方保证金冻结、信用分、纠纷仲裁三重机制保障学生权益。
