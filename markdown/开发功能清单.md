# FrameLab 功能与实现路径清单（三端架构版）

> 每条 = 功能 + 具体运行路径/规则数值。所有数字均为初始方案，直接改。

## 一、三端架构总览

1. **客户端（主站）**：作品展示、接单派单、需求发布、实习招聘、创作者主页都在这里 —— 面向市场交易，是平台门面。开发期挂在主域路径下，后期可拆子域。
2. **教育端（独立平台）**：美学赏析、闯关实训、背书认证、教学评价 —— 面向学习成长。
3. **创作端（独立平台）**：灵感 AI、跳转外部创作工具、作品上传与作品集、工作流提取 —— 面向作品产出。
4. 三端一个账号通用；作品库、信用分、成长数据、积分三端共享互通。
5. **曝光度机制**：曝光度 = 作品被浏览 1 分 + 被收藏 5 分 + 收到邀约 20 分 + 商单成交 50 分；累计达 500 分解锁「工作流转教学」权限（详见第 23、48 条）。

## 二、账号与存储（三端通用）

6. 注册：邮箱 + 验证码登录，选学校 / 专业 / 年级；注册即送 1GB 存储空间 + 30 积分。
7. 上传文件限制单文件 25MB，支持 jpg / png / webp / psd / ai / pdf；超 25MB 提示压缩后重传。
8. 注册用户有 1GB 免费空间，超过 1GB 部分开始收费：5 元/GB/月，或开通会员 15 元/月含 10GB（二选一，价格可调）。
9. 空间不足时上传被拦截，弹窗引导三选一：清理旧作品 / 升级空间 / 把作品转移到教育端归档或客户端公开展示区（转移后不再占用个人空间），并显示当前占用明细。
10. 甲方入驻需实名认证 + 营业执照（企业）或学生证（社团），审核通过后才能发布订单和招聘。
11. 教育端内容发布资质：发布教学内容、课程、或参与评分复核的用户，需背书审核 —— 高校教师在职证明 / 工信部等权威认证证书 / 职业资格证书 / 平台内 L4 通关 + 信用分 90+ 四选一，通过后授予「认证讲师 / 认证审核员」标记。

## 三、创作端

12. 灵感 AI 输入：创作主题 + 当前风格 + 自身痛点（4 个预设标签：同质化 / 缺创意 / 构图配色固化 / 主题难落地）。
13. 灵感 AI 输出：调用大模型 API（智谱 / 文心，密钥走配置），注入专属提示词库做上下文，输出六维方案 —— 差异化创意 / 小众风格推荐 / 构图思路 / 配色体系（附 hex 色板）/ 画面亮点 / 避坑指南（能力对标悟空图像 AI 闪绘、NanoBanana 这类制图 AI 的辅助层）。
14. 每用户每天免费 5 次灵感生成，超出 1 积分/次；每次调用记录云端留存，作为原创依据。
15. 专属工作流：六维方案可存为「我的工作流模板」，下次创作直接复用、微调；模板积累到 3 个可申请公开分享。
16. 内置敏感词过滤与侵权规避，违规输入直接拦截并提示。
17. 跳转外部专业工具平台（如悟空图像、即梦、LibLib）：新窗口打开并自动预填创作主题与参数。
18. 用户在外部工具创作完成后，作品导出保存到本地，再回到平台上传到系统相册，云端可直接访问。
19. 上传时自动识别风格标签（识别不准可手选），来源标记「外部工具创作」，记录上传时间作为原创时间戳。
20. 作品集实时风格分析 + 自动排版：每次上传后系统按风格归类并增量更新作品集排版（或融入为新风格板块）；可确认导出（PDF / 长图）或暂存继续上传。
21. 对比功能：① 双案例同屏对比（色彩饱和度、构图密度、视觉气质）；② AI 润色前后对比 —— 草图与成稿并排校验风格是否漂移，辅助定稿决策。
22. 作品集分享版权保护：对外链接默认加作者水印 + 禁止右键保存（作者可选关闭），免登录可看。
23. 工作流提取：创作端自动记录「灵感方案 → 提示词 → 草图 → 修改版本 → 成稿」全链路，一键打包为「工作流案例」。
24. 工作流曝光：曝光度达标（第 5 条）后，工作流案例可发布至客户端公开案例区（对外曝光）与创作端社区（局域曝光），作者署名并获得积分。
25. 站内简易出图兜底（后期接入绘画模型 API）：输入提示词 → 返回 4 张 → 选优入作品集。

## 四、教育端

26. 素材来源：官方公开授权渠道定向采集（WikiArt、大都会、Behance、Dribbble、站酷），只收 1080P 以上、无水印、无侵权素材，统一命名「风格 - 作品名称 - 作者 - 年份 - 适用场景」入库。
27. 素材检索：三级筛选（板块 / 流派风格 / 关键词）+ 分页，每页 20 张。
28. 每日推送分流：每天 3 张精选 + 五维解析 —— 客户端按用户接单方向推送对应商单案例风格，教育端同步推送相关知识点教学与精进内容，两端口径一致。
29. 素材详情：五维解析（构图亮点 / 色彩逻辑 / 视觉层级 / 美学韵律 / 可借鉴点）。
30. 收藏：可建对标收藏夹（上限 8 个），创作、闯关、接单时可一键调取参考。
31. 美学评分：六维加权百分制 —— 构图 25% + 色彩 25% + 层级 15% + 留白 10% + 风格 15% + 创意 10%；AI 初评 + 人工复核双轨，人工复核员须持教育端背书认证（第 11 条），评分与复核记录双留痕可查。
32. 四级闯关体系：L1 软件基础 → L2 平面进阶 → L3 三维建模 → L4 商业高阶，共 16 关。
33. 每关流程：知识点学习 → 商单需求案例拆解实操（案例取自客户端已完结订单，脱敏并经甲方授权）→ 完整命题作业（上传，≤25MB）→ 美学评分 → 通关判定。
34. 通关分 = 规范正确率 30% + 美学得分 40% + 创意得分 20% + 完整度 10%，≥ 80 分通关，自动解锁下一关。
35. 未达标自动推送薄弱知识点、优化建议、补学内容 + 对应教程，可重做（不限次数）。
36. 成长图谱：自动记录每关得分、薄弱模块、进步轨迹，可视化呈现。
37. 教学评价：完成关卡 / 课程 / 被采纳工作流教学内容，均计入教学评价记录，进入能力档案。

## 五、客户端（主站）

38. 甲方发布订单：填需求、预算、周期、交付标准；发布时冻结保证金（订单金额 20%，最低 50 元），7 天无人抢单自动解冻。
39. 智能匹配：按通关率 30% + 美学均分 25% + 风格标签重合 25% + 接单评价 10% + 学习稳定性 10% 计算匹配度，>85% 标「强烈推荐」。
40. 抢单门槛：L2 及以上可接 ≤500 元订单；500-2000 元需 L3 + 信用分 85+；2000 元以上需 L4 + 信用分 90+。
41. 信用分：初始 90 分，违约 -10，差评 -5，好评 +2，满分 100；低于 60 分冻结接单 3 天（冻结期内不可接新单，进行中订单不受影响）；信用分越高订单曝光率越高，形成接单量正循环。
42. 履约流程：已接单 → 已交付 → 平台初审 → 甲方验收 → 结算，每步留痕可查；已完结订单作品自动进入个人作品集公开展示。
43. 结算：验收通过后 T+3 打款，平台抽成 10%（可调）；保证金随验收同步释放给甲方。
44. 纠纷仲裁：双方 72 小时内举证，平台介入裁定，支持部分退款。
45. 实习岗位来源：接单平台甲方项目化招聘优先（合作过、知根底）+ 高校就业网 + 实习平台 + 文创企业直投，全部经人工资质审核后展示，标注「已核验」。
46. 一键投递：自动附带能力档案 —— 作品集 + 成长图谱 + 六维雷达 + 信用分 + 平台成交评价 + 教学评价，生成「平台内推简历认证」，含金量高于裸投。
47. 创作者主页：自动聚合全部作品、美学均分、六维雷达图、信用分、能力标签，作品更新实时同步；企业可按风格、等级筛选，定向邀约面试；访客浏览、收藏、邀约次数对本人可见，作为市场反馈。

## 六、三端联动闭环

48. **工作流转教学管线**：创作端提取工作流（第 23 条）→ 曝光度达标后提交教育端审核 → 认证审核员评审通过 → 进入教育端案例库 / 对应关卡实训命题 → 作者获积分分成 + 背书记录 + 教学评价。
49. **主循环**：教育端学 → 创作端产出 → 客户端曝光变现 → 变现实绩回流教育端背书 → 解锁更高创作与接单权限，三端互为入口、互为出口。
